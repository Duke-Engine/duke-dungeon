# A party over the LAN

One player hosts, the others join, and they go down together. Built on what the engine already has — lock-step
over TCP (`MultiplayerSession`), a game's own orders on the wire (`GameMessage.GameOrder`), and a match started
from game code (`Duke3D.startMatch`) — with nothing added to the engine.

## The rules of a party

- **Co-op, up to four.** Seats 1..N are heroes (the host is seat 1), allies of each other; the dungeon is seat
  N+1 and plays itself. Alone is a party of one, and plays exactly as before.
- **Each player picks their own hero.** The pick travels as an order when the match starts, so every machine
  learns every hero on the same frame; the first floor is laid once all of them are in.
- **Everything a hero has is his own:** level, experience, skills and their ranks, the bag of loot. A chest goes
  to the hero who stands on it (a monster that casts no longer picks one up).
- **Falling is not the end of a party.** A fallen hero waits; the others fight on. The boss down, everyone goes
  down a floor — the fallen with them, standing again, keeping what they had. Only when every hero has fallen
  is the run lost, and a new one begins for all.
- **A floor's banners are everyone's; a level is only its owner's** — shown on that player's screen alone.
- **Someone's machine leaving** changes nothing in the world (it would not happen on the same frame everywhere):
  their hero stays, fighting on its own.

## Orders

Every order a player gives — cast, raise a skill, hold, attack-move, watch, and now the hero pick — is sent as a
`GameOrder` (`PartyOrders`), alone as well as in a party, so a party and a replay speak the same words. A
command a test posts directly is still heard.

## The front end

"Enter the dungeon" asks who goes in:

- **Alone** — the path it always was: how, where, who.
- **Host a party** — how many, how, where, who; then a waiting room naming the address the others type. When
  all have joined, the match is built from the host's settings and started.
- **Join a party** — who; then the address (remembered for next time) and a waiting room until the host starts.

What the host settles — endless or a stage, its seed or its name — goes to every guest in one line
(`PartyMatch`, versioned, so a guest on a different build is refused with a reason rather than desynced).

## Online, later

Nothing here is LAN-only: a guest joins an address and a port, so a host with the port open is already reachable
from anywhere. What online play adds is somewhere to meet when nobody can open a port — a relay or a server that
seats players — which is the engine's session to grow; every order already travels in the form it would need.

## Not in it

Chat (the engine carries it; the game has no box to type in yet), shared discovery of the floor (the client
uncovers the dark round the local player's own hero), a dedicated server.
