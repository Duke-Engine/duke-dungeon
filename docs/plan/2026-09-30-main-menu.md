# The main menu — Last Hero's front end, fit for Steam

Part of Last Hero (the owner's direction of 2026-09-30: a single-hero RPG in one open world, released on Steam). The
owner asked for a main menu fit for a Steam game and chose a **live 3D scene** behind it. It is built **after the
campaign**, because it opens what the campaign makes (saves, the hero chosen, the story's first words); this spec
says what it is now, and the code-level plan is written when the work starts, against the engine as E8 and E10 leave
it.

## What is there today

- The engine's stone menu (`StoneMenu`, `Shell`): a title, rows the game names (the dungeon's: "Enter the dungeon",
  Settings, Quit), keyboard only ("UP DOWN choose, ENTER take"), dressed by the game's `MenuStyle` (Cinzel lettering,
  stone, torch and bone colours in `hud.duke`). Questions before a start (`Shell.Question`): alone, host or join a
  party (`PartyFront`), which hero.
- A game may draw its own front end on its canvas (`Shell` drawn by the game) with a **backdrop** behind it: a match
  the game builds and the engine runs and draws while the front end is up (`Duke3D.backdrop`). The live scene needs
  no new engine feature to exist.
- Settings: the engine's Settings screen (size, fullscreen, …) saved in `~/.duke-engine/settings.properties`.

## What the player sees

1. **A splash** of two or three seconds, skippable: the engine's mark and the maker's name.
2. **The main menu** over the live scene, with its own music:
   - **The scene:** a small fixed map of the last free kingdom's gate at dusk: torches, banners, a fire, the hero the
     player last played (or a hooded stranger before the first game) standing by it; the camera drifting slowly round.
     After the ending, when the hero has become the villain, the scene shows the villain's seat instead — the cycle
     the story ends on.
   - **The title:** "Last Hero", large, over the scene; the version in a corner.
   - **The rows:** Continue (only when a save exists: the latest) · New Game · Load · Settings · Credits · Quit.
   - Mouse and keyboard both: hover lights a row, a click takes it, ESC goes back; each row has its sound; screens
     change with a short fade.
3. **New Game:** the hero is chosen (Rogue, Knight, Mage — each shown standing in the scene as it is picked), then the
   story's first words (the summoning), then the world.
4. **Load:** the save slots, each with the hero, level, place in the world, time played and date.
5. **Settings**, in tabs: Graphics (size, fullscreen, quality, anti-aliasing), Sound (master, music, effects), Controls
   (the keys, rebindable), Game (hit numbers, camera), Language.
6. **Credits:** the makers and every asset's author and licence, rolling (from `CREDITS.md`'s rows).
7. **Quit**, asked once.
8. **In the game, ESC** opens the pause menu in the same style: Resume · Save · Load · Settings · Main menu · Quit.

All words from data, in every language the game ships.

## Decided by default (the owner may change them)

- **Languages:** English and O'zbek at launch, English first for Steam; more later. Every word the player reads is
  already data, so a language is a set of words, not code.
- **Playing together (LAN):** not on the main menu until the campaign decides whether Last Hero keeps a party; the
  engine's host/join paths stay available if it does.
- **The hero is chosen on New Game,** not on Continue or Load.

## What it depends on

- The campaign's saves (Continue, Load, Save) and its first words (New Game).
- E8's client split: the front end's panels live beside the side that draws them.
- The language setting: a way to pick which words the game reads.
- Steam itself (achievements, cloud saves, the overlay) is the Steam-prep part's, not this one's; the menu leaves room
  for it (a cloud mark on a save slot).

## Done when

- A first launch shows the splash, then the menu over the live scene with its music, at 60 fps, within a few seconds.
- Every row works by mouse and by keyboard; ESC always goes back; nothing on it is a placeholder.
- Continue loads the latest save; New Game walks hero, first words, world; Load shows and loads every slot.
- Settings change live and are remembered; Controls rebinds keys; Language switches every word.
- The pause menu does the same in the game.
- Credits name every asset's maker and licence.
